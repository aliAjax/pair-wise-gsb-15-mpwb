# FlowDesk Studio

FlowDesk Studio 是一个完全运行在浏览器中的企业级低代码流程编排与审批监控演示平台。项目使用 React、TypeScript、Vite、Zustand 和 React Flow，所有数据均为本地 mock，不需要后端、登录或外部 API。

## 启动

需要 Node.js 20+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址（默认 `http://localhost:5173`）。建议使用 1440px 或更宽的现代桌面浏览器。

## 测试

首次运行先安装 Chromium：

```bash
npx playwright install chromium
npm test
```

Playwright 会自动启动 Vite（端口 4173），串行验证 Dashboard、编辑器审批配置、双区域校验、条件修复、动态表单预览、发布联动、异常实例详情、版本比较和历史恢复。测试失败时会保留截图和 trace。

## 浏览器验证路径

1. Dashboard 点击“差旅费用审批”进入编辑器。
2. 选择“直属主管审批”，切换审批人来源并保存草稿。
3. 运行校验，观察 Condition 节点红色错误态和底部问题面板。
4. 选择“金额判断”，配置申请金额大于 5000，再次校验。
5. 打开预览，输入金额 12000，观察模拟分支切换。
6. 返回并发布；在 Dashboard 和 Workflows 检查状态及版本。
7. 进入运行监控，筛选异常并打开实例，查看时间线及高亮节点。
8. 从编辑器进入版本历史，选择两个版本比较，再恢复旧版本为草稿。

## 项目结构

- `mock-data/`：12 个流程、80 个实例、8 个用户、6 个角色、5 个业务域及边界案例。
- `src/components/`：布局、公共状态组件、React Flow 画布与全局检索（`GlobalSearch`、`IndexPanel`）。
- `src/pages/`：Dashboard、流程列表、编辑器、表单预览、运行监控、版本历史。
- `src/store/`：Zustand 全局状态、校验、发布、复制、归档及恢复逻辑（含修订号与跨窗口广播）。
- `src/search/`：全局检索引擎（修订号 CAS 写入、检查点构建、旧版升级隔离、权限过滤）。
- `src/types/`：核心业务数据 TypeScript 类型。
- `tests/`：关键产品链路与全局检索 Playwright 测试。

## 全局检索（Search Index）

顶部搜索框（`⌘K`）覆盖流程、实例与流程版本，行为对应一套独立的索引引擎（`src/search/engine.ts`）：

- **失效即重算**：流程保存/发布/恢复/复制/归档后，相关流程、版本及其实例键立即移出可用索引并进入待重建，构建完成按新内容回写，页面显示命中数与索引更新时间，选中结果直达编辑器、版本历史或实例详情。
- **权限**：角色按业务域授权，流程编辑人与申请人本人可见；陈默（采购专员）检索不到财务等无权域的流程与他人实例。查询时逐条鉴权，隔离记录不进入结果。
- **修订号 CAS**：两个窗口同时改同一条记录时，只接受修订号更新的索引写入；后到的旧结果不会覆盖新条目，而是进入待重建队列。窗口间通过 BroadcastChannel 同步业务数据与索引提交。
- **检查点构建**：全量/重建分批执行，每批落盘检查点；构建中途失败（索引状态面板可模拟）后从检查点继续，重复扫描不会产生重复条目。
- **旧版升级**：首次启动模拟从 v1.4.0 迁移，保留可用索引、落后条目并入重建，无法判断权限的残留记录进入“权限隔离区”由管理员核验（释放为待重建或放弃）。
- 右上角用户切换可切换视角（林秋为系统管理员，拥有全部权限）。

## Mock 边界案例

数据集中包含空流程、孤立审批节点、缺少结束节点、未配置条件分支、审批人为空、表单必填校验、超长流程名称、超长说明展示能力、无异常实例，以及由搜索筛选产生的空结果状态。
