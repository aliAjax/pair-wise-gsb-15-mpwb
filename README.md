# FlowDesk Studio

FlowDesk Studio 是一个完全运行在浏览器中的企业级低代码流程编排与审批监控演示平台。项目使用 React、TypeScript、Vite、Zustand 和 React Flow，所有数据均为本地 mock，不需要后端、登录或外部 API。

## 启动

需要 Node.js 20+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址（默认 `http://localhost:5173`）。建议使用 1440px 或更宽的现代桌面浏览器。

## 测试

首次运行先安装 Chromium：

```bash
npx playwright install chromium
npm test
```

Playwright 会自动启动 Vite（端口 4173），串行验证 Dashboard、编辑器审批配置、双区域校验、条件修复、动态表单预览、发布联动、异常实例详情、版本比较和历史恢复。测试失败时会保留截图和 trace。

## 浏览器验证路径

1. Dashboard 点击“差旅费用审批”进入编辑器。
2. 选择“直属主管审批”，切换审批人来源并保存草稿。
3. 运行校验，观察 Condition 节点红色错误态和底部问题面板。
4. 选择“金额判断”，配置申请金额大于 5000，再次校验。
5. 打开预览，输入金额 12000，观察模拟分支切换。
6. 返回并发布；在 Dashboard 和 Workflows 检查状态及版本。
7. 进入运行监控，筛选异常并打开实例，查看时间线及高亮节点。
8. 从编辑器进入版本历史，选择两个版本比较，再恢复旧版本为草稿。

## 全局检索

顶栏搜索框是带索引的全局检索，覆盖流程、流程版本和运行实例：

- **失效与重算**：流程、实例、版本变更后，对应文档立即从索引移除（旧内容不可再被搜到），并按新内容异步重算。
- **权限过滤**：结果按当前身份过滤（顶栏可切换林秋/陈默）。流程可配置访问名单（`acl`），实例权限跟随所属流程、申请人始终可见自己的实例；陈默看不到无权访问的流程和实例。
- **并发守卫**：索引写入携带修订号，只接收带最新修订号的写入；后到的旧结果自动进入待重建队列，随后按当前内容重算排空。
- **断点续建**：全量构建按批次落检查点（localStorage 持久化），中途失败/刷新后从上次检查点继续；文档按 id upsert，重复扫描不产生重复条目。
- **旧数据升级**：启动时检测 v1 旧快照并迁移——修订号匹配的可用索引直接保留，缺少权限信息的记录隔离待核（不可检索，可在面板中“重新扫描”复核），源已删除或内容过期的条目丢弃重建。
- 面板显示命中数与索引更新时间，选中结果直接打开原对象（流程→编辑器，实例→监控详情，版本→版本历史）。

索引状态（文档数、待重建、隔离数、检查点、迁移报告）可通过 `window.__search.status()` 查看，`__search` 还提供 `applyStaleWrite`/`rebuildAll`/`failNextBuildAt` 等测试钩子。

## 项目结构

- `mock-data/`：12 个流程、80 个实例、8 个用户、6 个角色、5 个业务域及边界案例。
- `src/search/`：检索引擎（文档、修订号、检查点、迁移）与源数据提取。
- `src/components/`：布局、全局搜索、公共状态组件和 React Flow 画布。
- `src/pages/`：Dashboard、流程列表、编辑器、表单预览、运行监控、版本历史。
- `src/store/`：Zustand 全局状态、校验、发布、复制、归档、恢复及搜索索引编排。
- `src/types/`：核心业务数据 TypeScript 类型。
- `tests/`：关键产品链路 Playwright 测试。

## Mock 边界案例

数据集中包含空流程、孤立审批节点、缺少结束节点、未配置条件分支、审批人为空、表单必填校验、超长流程名称、超长说明展示能力、无异常实例，以及由搜索筛选产生的空结果状态。
